Placement and host-load control
-------------------------------
All Fabric containers, CouchDB instances, local benchmark clients, temporary
preprocessing signers, and independent committee processes ran on this one
physical host. No remote machine was used. The Fabric stack contained 20 running
containers: one orderer, nine peers, nine CouchDB instances, and one CCaaS
chaincode container. Therefore the old informal description "18 containers" is
not correct for these reruns.

The experiments did not use CPU pinning, a dedicated bare-metal host, or an
automated host-load guard. Whether every unrelated high-load desktop program was
closed for every sample is NOT RECORDED. No stronger isolation claim should be
made. No timing observation was removed because of observed host load.

Cryptographic implementation
----------------------------
Hash/HMAC diagnostic code: Go crypto/sha256 and crypto/hmac.
Production preprocessing authentication: Go crypto/ecdsa, elliptic.P256,
crypto/x509, ecdsa.SignASN1, and ecdsa.VerifyASN1.
Committee authentication: ECDSA P-256 with canonical SHA-256 result digests and
distinct current-epoch signer enforcement in chaincode.

RSA accumulator: project implementation in chaincode/retf-core/rsa_accumulator;
there is no third-party accumulator library or library version. The current
construction uses domain-separated SHA-256 and deterministic search for a
256-bit probable-prime representative. The production experiment uses a 2048-bit
public modulus. Prime search is included in hash-to-prime measurements; RSA setup
and p/q generation are outside operation timings. The private factors p and q are
not stored in chaincode state or the publication artifact.

Private-key handling
--------------------
Fabric Admin MSP material was copied from the running peer into a temporary
directory for the one-command clients. Preprocessing and committee keys were
generated temporarily. Temporary directories were deleted after each run. The
publication artifact excludes Fabric crypto material, private keys, binaries,
Fabric CA databases, and Docker volumes.
